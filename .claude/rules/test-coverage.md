# 測試覆蓋

測試數會隨開發變動，不在這裡寫死。查法：

```bash
cargo test -- --list 2>/dev/null | grep -c ': test$'    # 全部（含 1 個 #[ignore] 的地圖診斷；cargo nextest run 的 Summary 不算它）
cargo test -- --list 2>/dev/null | grep ': test$' | awk -F'::' '{print $1}' | sort | uniq -c    # 各模組（第一層）
cargo test -- --list 2>/dev/null | grep ': test$' | awk -F'::' '{print $1"::"$2}' | sort | uniq -c    # 子模組（例如 world::map_data）
```

各模組涵蓋的範圍：

| 模組                 | 覆蓋範圍                     |
|--------------------|--------------------------|
| combat             | 武器、傷害、護甲、布娃娃、出血、自動瞄準、狙擊槍、RPG、受傷方向指示、kill cam 慢動作、舉手投降時不能射擊與投擲／引爆爆炸物 |
| vehicle            | 血量、輪胎、交通燈、改裝、爆炸、水上載具、碰撞變形  |
| economy            | 錢包、商店、ATM、股市、賭場、企業       |
| ui                 | 通知、互動提示、手機、股市、改裝商店、存檔 UI、小地圖與大地圖的投影和玩家箭頭、GPS 方向與轉彎提示、太陽光芒與命中標記、地圖快照、WASTED 慢動作與重生、BUSTED 播完才處理逮捕（只處理一次） |
| mission            | 任務目標、評分、對話、劇情、支線         |
| pedestrian         | 恐慌波、尋路、目擊者、行為、游泳、越界線與逃跑範圍 |
| camera             | pitch 限制、距離調整、角度正規化      |
| player             | 攀爬、技能、角色切換、游泳、面向、上下車（路徑檢查、轉向與車門、跟車與碰撞體、在車上死亡或車不見）、騎車與中止上車不被當成游泳、只在水域裡游泳 |
| world/map_data     | 讀檔、資料檢查（路名、方向、交會、同名路段）、路口與斑馬線、車道、建築擺放、越界與逃跑範圍 |
| world/time_weather | 日照、太陽軌跡、夜間光源、天氣光照、天體、霓虹燈、窗戶亮燈穩定性、天空盒、霧、月亮淡出 |
| audio              | 電台系統、音量、淡入淡出             |
| ai                 | 狀態轉換、感知、逃跑               |
| save               | 序列化、存檔路徑                 |
| wanted             | 通緝等級、警察狀態、搜索區、警車生成方向、投降（警察與直升機停火、走近逮捕、處理後放下手、移動或死亡放下手）、通緝清掉收隊、交戰跟丟改搜索、警察與直升機射線瞄準玩家（視線、開槍、逮捕、直升機命中；矮牆／貼牆／圍籬／頂棚會擋） |
| world/roads        | 斑馬線條紋方向、道路方向照資料              |
| world/buildings    | 外牆貼圖與 mip 鏈、色盤、UV 投影、外牆套用系統、generic 外型 |
| core/spatial_hash  | 插入、查詢、邊界                 |
| environment        | 可破壞物件、碎片池                |
| world/setup        | 月亮不吃距離霧且可淡出、地面邊緣被霧蓋住   |

**覆蓋率目標**：
- 核心系統（combat, economy, ai）：> 80%
- UI 和呈現層：> 60%
- 整體專案：> 75%
